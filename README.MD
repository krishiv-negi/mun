# MUN Management & Allocation System


## About Our Project
Our Project is a MUN Management & Allocation System . We are building it to make the process of managing delegates and assigning them committees and portfolios easier and more organized.

Currently, a lot of MUN information is managed manually using forms, spreadsheets and different files. This can take a lot of time, especially when there are many delegates.

Our system will keep the important delegate information in one place and help organizers choose suitable committees and portfolios based on the delegates experience, preferences and available positions.
